# Fizz Buzz

- **Difficulty:** Easy
- **Topic:** Basic Algorithms
- **LeetCode:** https://leetcode.com/problems/fizz-buzz/

## Approach
Iterate from 1 to n. Multiples of 15 become FizzBuzz, multiples of 3 become Fizz, multiples of 5 become Buzz, and all other values are converted to strings.

## Complexity
- Time: O(n)
- Space: O(n)

## Test Cases
1. `n = 3` → `["1","2","Fizz"]`
2. `n = 5` → `["1","2","Fizz","4","Buzz"]`

## Edge Cases
- n = 1
- Multiples of both 3 and 5
